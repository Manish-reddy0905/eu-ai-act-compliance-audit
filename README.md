# EU AI Act Compliance Audit

## Project Overview
This project performs a legal and technical compliance audit for an AI medical diagnosis system under the EU AI Act and GDPR.

## Features
- EU AI Act risk classification
- SHAP explainability dashboard
- GDPR anonymization
- Human oversight framework
- AI transparency reporting

## Technologies Used
- Python
- Scikit-learn
- SHAP
- Pandas
- Google Colab

## Compliance Measures
- High-Risk AI classification
- Explainable AI
- Human override capability
- Data anonymization
- Privacy protection
